Q1. What is HTML?
HTML stands for Hyper Text Markup Language and is used to create the structure of web pages.

Q2. What is a Root Element?
The <html> tag is called the Root Element because it contains all other HTML elements.

Q3. What is a Parent Element?
An element that contains another element.

Q4. What is a Child Element?
An element placed inside another element.

Q5. What is a Container Element?
An element that can contain other HTML elements inside it.

Q6. What is the difference between Head and Body?
Head contains webpage information, while Body contains visible webpage content.

Q7. What is Nesting?
Placing one HTML element inside another HTML element is called Nesting.

Q8. What is DOM?
DOM stands for Document Object Model. It is the tree structure created by the browser from HTML.
